# 原创与 AI 使用说明（docs/ai_usage.md）

> 按比赛原创要求：作品在比赛期间原创开发；AI 仅作为编码与文案辅助工具，方案设计、数据核验、结论判定由人工负责。
> 声明范围：本文件如实披露本作品在开发、数据整理、文档撰写中使用 AI 的环节与边界。
> 提交用途：本文件可作为 ANS「原创声明与 AI 模型使用说明」的正文或附件。

## 1. 开发方式

- 仓库从**空目录**开始（首次提交见 git 历史），全部代码、数据、文档在比赛期间完成；无旧项目复用、无外部项目代码拷贝。
- 采用「人类定方向 + 多 AI 智能体协作」的开发方式：Lead 负责架构、契约、核心问答管线与验收；4 个协作智能体分别负责知识图谱与数据、图查询与实体链接、Web 界面、测试与评测（写入范围互不重叠）。
- 依赖均为公开开源库：`streamlit`、`openai`、`pandas`、`python-dotenv`、`pytest`；未使用任何需授权的私有代码。

## 1.1 过去 48 小时新增内容与所用模型/工具

**2026-11-21 至 2026-11-22（提交前 48 小时）主要新增：**

- 知识数据更新为当前口径：58 个知识实体、115 条三元组、19 条来源，其中 69 条 `verified`、46 条 `anchor`；
- 检索与问答修正：补充设施停用词、别名与症状词，聚焦主题证据，限制跨品种参数误用；
- 证据约束加固：增加 `anchor` 确定性措辞检测（`anchor_overclaim`）、无效 `[E#]` 引用清理与最终引用守卫；校验不通过时回退模板或明确拒答；
- 回归测试与文档：新增证据等级/引用边界测试，当前 `pytest` 为 **325 passed / 2 skipped**；同步 README、技术摘要和展示材料。

**实际使用的模型与工具：**

- 在线问答模型：**DeepSeek**（通过 OpenAI 兼容接口）；离线模式不调用任何大模型，只使用模板。
- 开发辅助：多 AI 编程智能体（DeepSeek Harness）参与代码、测试与文档起草；方案、数据口径、核验结论由人工判定。
- 工程工具：Python 3.12、Streamlit、pandas、pytest、Ruff、Kùzu（Neo4j 为可选后端）；文档/PPT 使用 LibreOffice 做导出与视觉检查。
- **未使用 Ling-3.1-flash / Ling-3.2 等其他模型**；如平台要求列出所有模型，以上为实际使用清单。

**开源基础说明：** 本项目从空仓库开发，没有基于其他开源项目二次开发；仅使用上述公开依赖库。

## 2. AI 参与环节与人工把关

| 环节 | AI 参与 | 人工把关 |
|---|---|---|
| 方案与任务拆解 | AI 辅助列出阶段、验收标准、风险 | Lead 逐条评审并写入 `docs/api.md` / `docs/spec.md` 作为唯一口径 |
| 知识图谱 schema | AI 生成实体/关系初稿 | 人工定夺 5 类实体、9 种关系、双来源规则、anchor/verified 分级 |
| 文献与来源整理 | AI 检索、摘录公开描述 | **禁用编造作者/期刊/DOI**；不确定字段留空 + `note` 标注「待补链接」；国标发布/实施日期经 openstd 页面核对 |
| 三元组数据 | AI 按 schema 抽取条目 | 人工逐条检查类型-谓词合法、数值区间、来源外键；已获取国标全文 + 5 篇综述 PDF 后，与原文逐字对应/可由原文直接推出的 **69 条升级 `verified`**（含新增 MOA/2018 来源 8 条）并附条款号/页码+原文摘录，其余保持 `status=anchor` |
| 代码实现 | AI 编写代码与测试 | 人工代码评审、契约冻结、跑全量测试与实机验证（HTTP 200 / AppTest） |
| 问答答案 | 在线模式由 DeepSeek 生成 | 生成内容需通过引用校验 + 数值一致性校验；不通过回退模板，证据不足则明确说「未收录」 |
| 文案材料 | AI 起草简介、录屏脚本、README | 人工核对数据规模、指标与事实，避免夸大 |

## 3. 数据合规

- 来源均为公开标准与公开出版物（清单见 `docs/sources.md`），未使用未授权数据集；正文需购买/机构访问的，仅按公开的题录、摘要与发布信息入图，并标注获取状态。
- 未编造任何作者、期刊、DOI、页码或数值；无法核验的字段留空并在 `note` 说明，这是 `status=anchor` 的设计目的。
- 作品知识产权归参赛团队；主办方与合作方享有非商业赛事宣传展示权（依比赛规程）。

## 5. 边界声明

- 本作品是**辅助决策工具**，不替代持证农技人员的安全用药与检疫判定；涉及化学处理、气调参数的答案均提示「首次小批量试」。
