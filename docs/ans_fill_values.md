## 简介正文（直接粘）

鲜食葡萄采后贮藏涉及品种、温湿度、气体、预冷和保鲜处理等多类参数，资料分散且口径不一。我们把 GB/T 16862-2026 及相关综述整理为 63 个知识实体、125 条三元组、45 条来源的知识图谱，每条关系带来源与核验状态（69 verified / 56 anchor）。系统先做实体链接、主题路由与图谱检索，再让模板或大模型在证据约束下生成回答，并检查引用与数值；证据不足时明确拒答。

## 提交后核对

1. 页面显示「正式提交」成功/历史记录出现本条；
2. 公网地址能打开、示例问题能答（提交前自己点一遍）；
3. GitHub 仓库 README 顶部有公网地址、无 `.env`/PDF；
4. 提交前执行 `git rev-parse HEAD` 记录最终 commit，确认平台版本快照与该 commit 一致；若页面要求源码压缩包，用同一 commit 重新运行 `.\scripts\make_release.ps1 -Version v1.4.1` 并核对 `MANIFEST-v1.4.1.md` 中的「代码版本」与 SHA256，避免“快照旧、材料新”；
5. 公网 Demo 若仍为旧版，先按 `docs/deploy.md` 上传新包，不要声称已更新。
