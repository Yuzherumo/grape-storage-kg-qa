## 简介正文（直接粘）

鲜食葡萄采后损耗，不是技术不够，而是规范没人读得下去。我们把现行国标 GB/T 16862-2026 与 5 篇综述中的储藏规范拆成 74 节点、108 条三元组的知识图谱：品种、储藏条件、品质指标、病害互连，每条带来源与定位。农户和冷库管理员用大白话问「阳光玫瑰放冷库几度」「葡萄长白毛咋办」，系统先识别品种与病害再查图谱，让大模型只能引用证据生成「结论＋依据＋现在该做什么」，数字可溯源；没收录就直说。
