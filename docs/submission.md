## 200 字简介（提交用，正文约 190 字）

鲜食葡萄采后贮藏涉及品种、温湿度、气体、预冷和保鲜处理等多类参数，资料分散且口径不一。我们把 GB/T 16862-2026 及相关综述整理为 63 个知识实体、125 条三元组、45 条来源的知识图谱，每条关系带来源与核验状态（69 verified / 56 anchor）。系统先做实体链接、主题路由与图谱检索，再让模板或大模型在证据约束下生成回答，并检查引用与数值；证据不足时明确拒答。

> 若平台按「汉字数」统计，仍满足 200 字上限；提交前以平台计数器为准。

## 一页要点（答辩 / 推文用）

**一句话**：把葡萄储藏国标做成农户问得出、听得懂、查得到来源、还能照做的知识图谱问答。

**痛点**：采后损耗高，参数靠经验；SO₂ 用错会毁货；灰霉爆发不知从哪下手；不知道什么时候该出库。

**怎么做的**
1. 图谱：5 类实体 108 节点、9 种关系 125 条边，条级溯源（`source_ids + locator + quote + status`）；**69 条已升级 verified、56 条 anchor 待核验**（69 条中 53 条 `source_ids` 含国标，其中 37 条仅引国标；按升级依据为 51 条国标条文 + 10 条综述原文 + 8 条 MOA/2018 论文，带条款号/页码+原文摘录），其余标「待核验」；
2. 问答：实体链接 → 意图路由 → 参数化查图 → 证据编号 → 模板或 DeepSeek 生成「结论/依据/现在该做什么」，生成内容必须通过引用与数值校验；
3. 可信：引用校验 + 数值一致性（单位/±区间/越界）双层拦截，越界问题直接说不可行；
4. 可用：口语/错别字容错、大字模式、无 API Key/断网自动降级模板模式。

**硬指标**
- 离线可复现评测：**28 题全过**（answer 19 + refuse 9）：意图 100%、主实体覆盖 100%、引用有效率 100%、数值一致率 100%、拒答准确率 9/9、口语变体 12/12；Q6 命中 `out_of_range`；
- 测试：`pytest tests -q` → **418 passed / 2 skipped**（无网可跑；覆盖率 83%）；
- 图谱：108 节点 / 125 条关系 / 10 个查询模板；数据十项校验全绿；**69 条证据已按国标/综述/MOA/论文原文 verified**。

**差异化（相对普通 RAG）**
检索单位是三元组而不是文本块 → 能做品种对比、禁忌/替代推理、区间越界判断；每条证据可点到来源与核验状态。

**目标用户**：种植户/合作社（入库参数）、冷库管理员（巡检处置）、采购质检（到货判定）、农技员与学生（学习对比）。

**技术栈**：Python 3.12 + Streamlit + DeepSeek（OpenAI 兼容）+ 纯标准库图检索；Neo4j Cypher 脚本完整交付（可选后端）。
