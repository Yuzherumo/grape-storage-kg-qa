# 3 分钟录屏脚本（docs/demo_script.md）

> 目标：3 分钟内让评委看到「真实痛点 → 图谱证据 → 分步动作 → 不编造 → 离线可用」。
> 启动：`.\run.ps1` → `http://127.0.0.1:8501`。录屏前先跑 `.\run.ps1 -Check` 确认数据与图谱自检通过。
> 若现场无 `DEEPSEEK_API_KEY`：全程离线模式，开场加一句「现在演示的是离线保底路径，现场无网也会这样答」，反而体现稳定性。

## 分镜表

| 时间 | 画面 / 操作 | 旁白（可直接念） |
|---|---|---|
| 0:00–0:30 | 停在首页（侧栏显示 后端 local / 模型状态 / 图谱统计 69 节点 108 关系） | 「鲜食葡萄采后损耗，不是没技术，是规范没人读得下去。国标里写清了温度、湿度、SO₂ 禁忌，但一线手里只有一句『大概放冷库吧』。我们把这些规范做成了能查、能溯源、能照做的知识图谱问答。」 |

## 关键话术（评委追问时的 30 秒回答）

- **「这不就是 RAG 吗？」** → 「检索的不是文本块，是带谓词的三元组。所以能做三件事：品种对比、禁忌/替代推理、区间越界判断；每句话还能点到条级来源。普通 RAG 做不到。」
- **「数据从哪来、可信吗？」** → 「P0 是现行国标 GB/T 16862-2026（2026-10-01 实施），我们拿到了全文，**51 条已标 verified，带条款号和原文摘录**（§7.3 温湿度、§7.4.1 温度波动、§5.3.2 预冷 12h、附录A 八个品种糖酸、附录B 五种病害防治）；剩下 57 条因为综述/论文正文没拿到，一律标 anchor『待核验』——分级透明，不冒充条文。」
- **「大模型编了怎么办？」** → 「两道闸：引用校验（答案里的 [E#] 必须真实存在）+ 数值一致性（数字必须落在证据区间内，否则黄色告警）。演示里 [E#] 和证据表是一一对应的。」
- **「离线怎么办？」** → 「侧栏有离线模式开关，刚才全程就是离线模板模式：答案仍是证据拼装 + 分步动作，不是一句『服务不可用』。」
- **「原创性？」** → 「空仓库到成品 6 小时，git 历史可查；AI 只做编码与文案辅助，来源与数值是人工核验的，见 docs/ai_usage.md。」

## 彩排清单（录屏前 5 分钟）

1. `.\run.ps1 -Check` → 十项校验通过、图谱统计 69 节点/108 条关系；
2. 浏览器打开 8501，清空历史；
3. 按 ①→②→③→⑤→⑥ 顺序点一遍，确认每条都出「结论/依据/现在该做什么/证据表」；
4. 确认 `-18℃` 题出现 `out_of_range` 黄色告警；
5. 切换大字模式一次，确认字号变化且不破版；
6. 若配了 key，先测一次在线模式，再切回离线模式录一条保底。
